It's a progress affordance

The comet ribbon is work made visible — length maps to progress, and the trail you see fading is where Viibi has just been. Processing stops being a hidden spinner.

It's the containment

When Viibi holds the ⛨ shield, the sandbox is sealed. The mascot and the security model agree on one symbol, so the product's premise finally has a face.

It's quiet

Viibi respects reduced-motion, idles to near-invisibility, and never speaks. It glows when there is work and sleeps when there isn't.

This page is the design pass. The next step is extracting Viibi into src/renderer/viibi.js and driving its state from the real event stream — agent spawn, flow runs, conductor streaming, voice transcription, and blocked-host events.
