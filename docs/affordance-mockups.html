draftfrontend & affordance

Tome's differentiators are invisible by default.

The containment, the allowlist, the conductor's tools — they all work, and they all hide. These six mockups are the same app, rebuilt in HTML, with the changes that make each one perceivable, reachable, and auditable. Every mockup is a machine you can drive, not a still.

Spend the capabilities already built

None of these mockups invent a subsystem. Each one makes a working safety property perceivable, a working feature reachable, or an assistant action auditable — the same through-line as docs/AFFORDANCES-PLAN.md. This page is a proposal in the same design language as the app; the code that realizes it lives with the rest of Tome.
